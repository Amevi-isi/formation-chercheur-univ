# Formation en intelligence artificielle pour les femmes chercheures

Ce dépôt rassemble des supports de formation et des travaux pratiques en intelligence artificielle destinés aux chercheures. Les ressources sont organisées par module et, lorsque le contenu le prévoit, par parcours **IT** (avec programmation) et **non-IT**.

## Parcourir le dépôt

| Dossier | Parcours et contenu |
|---|---|
| [`module2/`](./module2/) | **IT — TAL/NLP et IA** : six thèmes, des fondamentaux du traitement automatique du langage aux pipelines de données. Supports, ateliers, quiz et notebooks participant/formateur. Voir le [README du module 2](./module2/README.md). |
| [`module2_nonIT/`](./module2_nonIT/) | **non-IT — Module 2** : fiche pédagogique, support de présentation, quiz et documents d’accompagnement. |
| [`module3/`](./module3/) | **IT — Réseaux de neurones et vision** : notebooks sur les bases du machine learning, les réseaux de neurones, les CNN et la détection d’objets. Voir le [README du module 3](./module3/README.md) pour les consignes d’exécution. |
| [`module3_nonIT/`](./module3_nonIT/) | **non-IT — Module 3** : supports d’introduction à l’analyse de données sans code avec Orange et KNIME. |
| [`module4/`](./module4/) | **Ateliers pratiques** : notebooks et données répartis par groupe thématique, ainsi qu’une application web pédagogique. Pour cette dernière, consulter le [README de l’application](./module4/application_web/README.md). |

Les dossiers correspondant aux volets IT et non-IT sont distincts : choisissez les ressources adaptées au parcours suivi. Les consignes et dépendances peuvent varier d’un module à l’autre ; il n’y a pas d’installation commune à l’ensemble du dépôt.

## Utiliser les ressources

- Les présentations et documents Word servent de supports de cours, d’ateliers ou de consignes.
- Les notebooks (`.ipynb`) s’ouvrent dans Jupyter, VS Code ou Google Colab. Suivez les instructions du notebook et du README de son module avant d’exécuter les cellules : certains exercices nécessitent des bibliothèques ou téléchargent des ressources.
- Les notebooks désignés **participant** sont prévus pour réaliser les exercices ; ceux désignés **formateur** contiennent les solutions.
- Les quiz sont disponibles sous différents formats selon le module. Dans le module 2, les fichiers JSON comprennent les réponses et leurs explications : ne les distribuez pas tels quels si le corrigé doit rester caché.
- Pour lancer l’application web du module 4, suivez les étapes d’installation et de démarrage indiquées dans son README dédié.

## À propos des exercices

Les notebooks et applications sont des supports pédagogiques. Leurs résultats dépendent des données, des modèles et des choix méthodologiques présentés dans chaque activité. Ils ne doivent pas être interprétés au-delà de la portée décrite par le module ; en particulier, l’application du module 4 précise qu’elle n’est ni un dispositif médical ni un système de décision publique.
